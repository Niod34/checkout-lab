# BUG-002 — Erro ao carregar o carrinho aparece como "carrinho vazio"

**Severidade:** Média · **Status:** Corrigido

## Descrição

Quando a requisição `GET /api/carts/:id` falhava, as páginas de carrinho e
checkout mostravam "Seu carrinho está vazio". O cliente achava que tinha perdido
os itens, mas o carrinho continuava salvo no servidor.

## Como foi encontrado

Alguns testes de carrinho falhavam de forma intermitente quando a suíte inteira
rodava em paralelo. O screenshot da falha mostrava o carrinho vazio logo depois
de ele ter sido montado pela API. Olhando o código, a página tratava qualquer
resposta diferente de 200 como carrinho vazio.

## Passos para reproduzir

1. Adicionar um produto ao carrinho
2. Fazer a API do carrinho responder com erro 500 (no teste isso é feito com `page.route`)
3. Abrir `/carrinho`

## Resultado esperado

Mensagem de erro informando que o carrinho não pôde ser carregado.

## Resultado obtido (antes da correção)

"Seu carrinho está vazio."

## Correção

As páginas passaram a exibir "Não foi possível carregar o carrinho (HTTP 500)"
em caso de erro. O 404 continua sendo tratado como carrinho vazio, porque nesse
caso o carrinho realmente não existe mais.
