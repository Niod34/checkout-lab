# BUG-001 — Cupom de desconto aumenta o total do pedido

**Severidade:** Alta · **Status:** Aberto

## Descrição

O frete grátis (a partir de R$ 200,00) é calculado sobre o valor já com desconto.
Quando o pedido está exatamente no limite, um cupom pequeno faz o cliente perder
o frete grátis e o total final fica maior do que sem cupom.

## Passos para reproduzir

1. Adicionar 2 unidades do Hub USB-C 7 em 1 (R$ 100,00 cada)
2. No checkout, calcular o frete para o CEP 01310-100
3. Aplicar o cupom `DESCONTO5` (R$ 5,00 de desconto)

## Resultado esperado

Total menor ou igual a R$ 200,00.

## Resultado obtido

|           | Sem cupom     | Com cupom     |
| --------- | ------------- | ------------- |
| Subtotal  | R$ 200,00     | R$ 200,00     |
| Desconto  | R$ 0,00       | R$ 5,00       |
| Frete     | grátis        | R$ 19,90      |
| **Total** | **R$ 200,00** | **R$ 214,90** |

## Testes relacionados

- `tests/api/quote.spec.ts` — BUG-001
- `tests/e2e/checkout.spec.ts` — BUG-001

Os testes validam o comportamento atual. Quando a regra for corrigida, eles devem
ser atualizados para o resultado esperado.

## Sugestão de correção

Não deixar o total com cupom passar do total sem cupom, ou avisar o cliente que
o cupom vai remover o frete grátis.
